# Contributing

This unofficial plugin is developed in public as an experimental source preview.
Use the pinned dependencies and build instructions in [Development](docs/Development.md).

For a bug, provide the OneWare version, plugin commit, OS/architecture, exact steps,
expected and observed behaviour, and a small fictional workbook when needed.
Screenshots should omit private documents, account details and personal paths.

Keep changes scoped to the plugin. Add a repeatable regression check when behaviour changes,
and describe native GUI verification separately from headless checks. Preserve upstream license notices.
Do not commit local profiles, generated binaries, dependency checkouts or temporary investigation output.
